# Acceptance is reversible — the Model never freezes

A Proposition becomes Accepted on the user's signal. But the Model grows through Probes that reveal new ground, and a Scenario produced from that new ground can break an already-Accepted Proposition. The question: once Accepted, is a Proposition frozen?

No. An Accepted Proposition **Degrades** — it returns to Candidate — when a later Scenario breaks it, on plausible justification. Acceptance is reversible.

**Consequence:** the Model is never frozen, and Satisfaction is always *provisional* — the user is satisfied as far as the current Scenarios reach, not as a claim that no future Scenario can break the Model. This is consistent with ADR-0002: ground truth accumulates with the user, so a Model that declared itself terminal would be asserting a completeness no agent can verify.

**Rejected alternative:** terminal Acceptance — simpler, but it would hide the contradictions that later Scenarios reveal, producing a Model that is frozen yet wrong.
